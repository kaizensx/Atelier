Releases

Beta first, always.

Every version ships as a beta, runs on real Macs, and only then is the same code promoted to stable. Atelier updates itself from here, and checks every download's signature before it installs.

Test

Built, signed and verified on the maintainer's Mac. Tests pass, the signature checks out, the app installs and runs.

Beta

Published as a pre-release. Macs on the Beta channel in Settings › Updates are offered it first.

Stable

The same code, promoted once the beta has run well. If anything changed since, another beta comes first.

Atom feed

Checking a download by hand

Each release carries the zip, its Ed25519 signature and a SHA-256 checksum. Compare the checksum with:

shasum -a 256 ~/Downloads/Atelier-*.zip

Choose your channel

Open Settings › Updates in Atelier. Stable gets finished releases only. Beta gets every build first. Roll Back puts the previous version back in one click.
