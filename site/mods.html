Mods

Made by the community.

Plugins add widgets, Dock tiles, commands and corner actions in sandboxed JavaScript. Themes restyle everything Atelier reaches, from one file. Every mod is reviewed in the open on GitHub.

Preview catalog. The community catalog opens with beta 2. These are the examples that ship with Atelier, shown the way shared mods will be.
Share yours

Submit a mod.

One folder, one pull request. A check validates it, a maintainer reads the code and tries it, and within minutes of the merge it is in everyone's Mods chapter.

1

Make it and try it

Drop your .atelierplugin or .ateliertheme on Themes & Plugins. Try a light setup and a dark one.

2

Pick an id

Reverse-DNS and yours, like io.github.you.focus-ring. It is permanent: updates follow it.

3

Add the folder

mod.json, description.md, 1 to 6 screenshots and the package, in mods/<id>/.

4

Open a pull request

The Validate check lists anything to fix. Permissions must match what the script uses.
