### New

- **Mods › Create**: a playground for plugins. Write a script in a code editor with line numbers and colouring, start from the Hello, Focus Timer, Web Feed or Controls template, and press Run. The widgets (with working buttons and toggles), Dock tiles, commands and corner actions it adds appear beside the code, drawn by Atelier itself and ready to click; events it listens for can be sent with a button; its console sits below. It runs in the real plugin runtime with no permissions unless you tick them, and Atelier asks on the permission sheet first. Save as Plugin writes a `.atelierplugin` folder and installs it. Search finds it as "Mod Playground".
- **atelier-mod**, a command-line kit for mod authors in `sdk/` (Node 20, no dependencies): `new` makes a plugin, theme or pack project with editor types and completion for the whole API (packs start as a small working example that passes Atelier's and the catalog's checks), `validate` runs the same checks as the catalog (it carries the catalog's own code), `test` runs a plugin outside Atelier behind Atelier's own prelude, with settings, buttons and toggles, translations, messages, every http method and the hooks (palette searches, menus, drops, stacks, live activities, Scenes, panels), and shows what it registered and drew, `pack` zips it exactly as the catalog does, and `catalog-entry` writes the folder for a pull request.
- **Making mods** guide (docs/MAKING-MODS.md) with a review checklist, and a **Make a mod** page on the website with the whole plugin API, searchable, with examples to copy.
- `docs/plugin-api.json`: the plugin API described in one machine-readable file, which the editor types, the kit and the website are built from.
