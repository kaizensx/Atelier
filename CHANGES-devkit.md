### New

- **Mods › Create**: a playground for plugins. Write a script in a code editor with line numbers and colouring, start from the Hello, Focus Timer or Web Feed template, and press Run. The widgets, Dock tiles, commands and corner actions it adds appear beside the code, drawn by Atelier itself and ready to click; events it listens for can be sent with a button; its console sits below. It runs in the real plugin runtime with no permissions unless you tick them, and Atelier asks on the permission sheet first. Save as Plugin writes a `.atelierplugin` folder and installs it. Search finds it as "Mod Playground".
- **atelier-mod**, a command-line kit for mod authors in `sdk/` (Node 20, no dependencies): `new` makes a plugin, theme or data pack project with editor types and completion for the whole API, `validate` runs the same checks as the catalog (it carries the catalog's own code), `test` runs a plugin outside Atelier behind Atelier's own prelude and shows what it registered and drew, `pack` zips it exactly as the catalog does, and `catalog-entry` writes the folder for a pull request.
- **Making mods** guide (docs/MAKING-MODS.md) with a review checklist, and a **Make a mod** page on the website with the whole plugin API, searchable, with examples to copy.
- `docs/plugin-api.json`: the plugin API described in one machine-readable file, which the editor types, the kit and the website are built from.
